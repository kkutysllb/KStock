# 运行说明（2.0）

KStock 2.0 只有一个业务进程：**QiLin 引擎（kstock profile）**。Electron 壳
负责拉起它、从 stdout 捕获启动 token 并加载工作台；所有业务面（对话、
公共页、量化四库 API、技能）都在引擎插件体系内。

## 进程与端口

| 项 | 值 |
|----|----|
| 引擎监听 | `http://127.0.0.1:18001`（壳固定端口） |
| 引擎 profile | `~/.kstock/qilin-home/profiles/kstock` |
| 引擎 home | `QILIN_HOME=~/.kstock/qilin-home` |
| 数据根 | `KSTOCK_APP_DATA_DIR=~/.kstock` |
| 预设根 | `KSTOCK_PRESETS_DIR`（dev 直跑引擎时指向 `kstock/presets`；打包态随闭包） |
| 技能 | 随包分发：preset 目录 + 安装闭包（含动效技能库）；无 `KSTOCK_SKILLS_DIR` 读取点 |

## 启动方式

**桌面端（推荐）**：`pnpm dev:desktop`。壳按以下顺序解析引擎：

1. 打包态内置运行时闭包（`resources/kstock-runtime.tar.gz` → 首启解压到
   `~/.kstock/runtime`，Electron 内置 Node 直跑，更新后按 tar 指纹自动重解压）
2. dev 兜底：系统 Node 直接跑 `vendor/qilin` CLI 源码（`--import tsx/esm`）

**浏览器直连**：手动启动引擎后访问 `http://127.0.0.1:18001/`（KStock 落地页）。
带启动 token 的 `/workspace?token=…` 可免登录直达工作台（会话有效期 7 天）。

## 数据面 API（/kstock-api）

四库路由由 `@kstock/quant` 宿主半端注册，与 1.x 网关响应形状一致：

- 策略 `/kstock-api/strategies`、因子 `/kstock-api/factors`、选股 `/kstock-api/selections`
  - `GET /` 列表（含 latest_run）、`POST /` 建、`PATCH /{id}` 改
  - `GET/POST /{id}/versions`、`GET /{id}/versions/{v}`
  - `GET/POST /{id}/runs`、`GET /{id}/runs/{run}/{attachment}`、`GET /{id}/compare?runs=a,b`
- 报告 `/kstock-api/reports`
  - `GET /?date=&symbol=&query=`、`GET /{id}`、`GET /{id}/content`（CSP sandbox）、
    `DELETE /{id}`、`POST /`（agent 入库口，body 含 `content` HTML 全文）

## 常见操作

- **重启引擎**：托盘/菜单「重启引擎」（壳整树终止后重新拉起并换新 token）
- **日志**：`~/.kstock/logs/desktop-engine.log`（引擎 stdout/stderr）
- **退出**：壳退出前会对引擎整树 SIGTERM → 超时 SIGKILL，防止端口残留
