# 运行说明

## 本地开发

```bash
pnpm install
python -m pip install -e ./sidecar
pnpm -C apps/desktop tauri:dev
```

如需模拟正式数据目录：

```bash
KSTOCK_APP_DATA_DIR=/tmp/kstock-app-data pnpm -C apps/desktop tauri:dev
```

这会启动 Tauri 原生桌面窗口。只想调试网页层时，才使用：

```bash
pnpm -C apps/desktop dev
```

## 运行测试

```bash
python -m pytest sidecar/tests -q
pnpm -C apps/desktop test
pnpm -C apps/desktop exec playwright test
```

## 构建产物

- `dist/kstock-sidecar.pyz`
- `apps/desktop/dist/`
- `apps/desktop/src-tauri/target/release/bundle/`
