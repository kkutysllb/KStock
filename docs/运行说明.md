# 运行说明

KStock 桌面端由两部分组成：

- **QiLin gateway**（Python / FastAPI）：内置在 `vendor/qilin`，由 `scripts/run_gateway.py` 以 uv 管理的虚拟环境启动，提供认证、线程、运行等 HTTP API。
- **桌面前端**（React + Tauri）：`apps/desktop`，通过 HTTP + Cookie 对接 gateway。

## 1. 环境准备

需要 Node.js、pnpm 与 [uv](https://docs.astral.sh/uv/)。

```bash
# 前端依赖
pnpm install

# Python 运行时：在项目根目录创建 .venv 并以 editable 方式安装 vendor/qilin
uv venv
uv sync
```

`uv sync` 会按根目录 `pyproject.toml` 安装 qilin 及 gateway 运行所需的 fastapi / uvicorn / bcrypt / email-validator 等。

## 2. 启动 gateway

```bash
uv run python scripts/run_gateway.py
```

默认监听 `http://localhost:18001`。启动时会：

1. 解析跨平台用户数据根目录（见下「用户数据空间」）并建立目录结构；
2. 生成运行时配置 `qilin.runtime.yaml`，显式写入 SQLite 绝对路径；
3. 注入桌面端 webview 的 CORS origin 白名单；
4. 打印数据根目录、运行时配置、QILIN_HOME、SQLite 路径、CORS origins。

可用环境变量覆盖：

| 变量 | 默认 | 说明 |
|------|------|------|
| `GATEWAY_HOST` | `localhost` | 绑定地址；保持 `localhost` 以满足前端 same-site cookie |
| `GATEWAY_PORT` | `18001` | 监听端口 |
| `GATEWAY_CORS_ORIGINS` | 内置桌面端 origin | 逗号分隔的额外允许 origin |
| `KSTOCK_APP_DATA_DIR` | 系统 app data 目录 | 覆盖用户数据根目录（多实例 / 调试用） |

## 3. 启动桌面端

```bash
# 网页层调试（Vite dev server，http://localhost:1420）
pnpm -C apps/desktop dev

# Tauri 原生桌面窗口（会自动拉起 Vite dev server）
pnpm -C apps/desktop tauri:dev
```

> 开发态前端默认连接 `http://localhost:18001`，可经 `apps/desktop/.env` 的 `VITE_GATEWAY_URL` 覆盖。

## 4. 用户数据空间

正式运行时用户数据落在跨平台系统应用数据目录（详见 `docs/用户数据空间组织设计.md`）：

- macOS：`~/Library/Application Support/KStock`
- Windows：`%APPDATA%\KStock`
- Linux：`~/.local/share/KStock`

结构：

```text
KStock/
  config/qilin.runtime.yaml      # 运行时配置（由 scripts/run_gateway.py 生成）
  runtime/qilin/
    data/qilin.db                # QiLin 主库（用户、线程、运行、会话）
    .jwt_secret                  # 认证 JWT 密钥
  product/  logs/  ...
```

> 仓库内不再保存任何用户数据；`.gitignore` 已防御性忽略 `.kstock/` 与 `.qilin/`。

## 5. 认证

gateway 自带完整本地账户体系（HttpOnly Cookie + JWT + CSRF）：

- 首次启动后，前端落地页点「注册」创建本地账户（邮箱 + 至少 8 位密码）；
- 注册成功后 gateway 同步下发会话 cookie，自动进入工作台；
- 下次启动时前端会探测 `/api/v1/auth/me`，已登录则直接进入工作台；
- 工作台侧边栏底部显示当前账户邮箱，可「退出登录」。

## 6. 运行测试

```bash
# Python（gateway 侧）
uv run pytest gateway/tests -q

# 前端单元测试
pnpm -C apps/desktop test

# Playwright 端到端
pnpm -C apps/desktop exec playwright test
```

## 7. 构建产物

- `apps/desktop/dist/`：前端构建产物
- `apps/desktop/src-tauri/target/release/bundle/`：Tauri 安装包
