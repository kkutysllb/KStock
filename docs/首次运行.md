# 首次运行

## 1. 安装依赖

```bash
pnpm install
python -m pip install -e ./sidecar
```

## 2. 启动桌面端

```bash
pnpm -C apps/desktop tauri:dev
```

这个命令打开的是 Tauri 原生桌面窗口。`pnpm -C apps/desktop dev` 只是网页层调试入口，不是桌面端验证入口。

## 3. 先看什么

- 左侧是会话列表
- 中间是对话工作台
- 右侧是报告和技能
- 底部是运行状态

## 4. 第一条研究请求

输入一个标的或主题，例如：

```text
分析贵州茅台最近一季财报，并生成报告。
```
