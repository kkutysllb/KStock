# 首次运行（2.0）

## 1. 构建

```bash
pnpm install
bash scripts/build-engine-bundle.sh
```

## 2. 首次启动

```bash
pnpm dev:desktop
```

壳会自动完成：

- 创建引擎 home 与 kstock profile（`~/.kstock/qilin-home/profiles/kstock`），
  插件依赖以符号链接指向插件包目录（dev=仓库 `kstock/`；安装包=resources）
- 拉起引擎并捕获启动 token，直接进入已登录的工作台

## 3. 管理员账户

桌面端经启动 token 免登录；浏览器直连场景首次访问 `/workspace` 会引导
**初始化管理员**（用户名 + 密码 ≥8 位）。注册默认关闭（单用户产品）。

**1.x 升级用户**：旧版邮箱账户自动迁移——首启引擎自动从旧库导入账户
（无需初始化），直接用旧邮箱 + 旧密码登录即可；旧密码首次登录成功后
自动升级为新哈希格式，无需重置。详见《2.0 特性差异与迁移说明》。

## 4. 验证清单

- 落地页 `http://127.0.0.1:18001/` 显示 KStock 品牌，引擎状态「已连接」
- 工作台侧栏出现「策略库 / 因子库 / 选股库 / 报告库」四个入口，各自面板可浏览
- 对话发一句话验证模型连通（需在设置中配置模型 API Key）
