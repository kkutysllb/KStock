# 首次运行

## 1. 安装依赖

```bash
# 前端
pnpm install

# Python 运行时（项目根目录创建 .venv，editable 安装 vendor/qilin）
uv venv
uv sync
```

## 2. 启动 gateway

打开一个终端，保持运行：

```bash
uv run python scripts/run_gateway.py
```

看到 `Uvicorn running on http://localhost:18001` 即表示 gateway 就绪。首次启动会在用户主目录 `~/.kstock` 初始化 SQLite 数据库与 JWT 密钥；若检测到历史版本（v1）系统应用数据目录（macOS 为 `~/Library/Application Support/KStock`），会自动整体迁移到 `~/.kstock`。

## 3. 启动桌面端

另开一个终端：

```bash
pnpm dev:desktop                  # Electron 原生桌面窗口（含 gateway 自启）
# 或仅调试网页层：pnpm -C apps/desktop dev
```

## 4. 创建账户

桌面端启动时会探测 gateway 的 `setup-status`，根据是否已有管理员自动选择创建方式：

### 首次启动（系统未初始化，无管理员）

1. 点「注册」，标题会显示为「初始化管理员账户」，提示该账户将成为管理员；
2. 填写邮箱、至少 8 位密码，并在「确认密码」中再次输入相同密码；
3. 勾选「记住我」可保持 7 天登录态；
4. 点「初始化并进入」，前端走 `POST /api/v1/auth/initialize` 创建 `system_role=admin` 账户，gateway 下发会话 cookie 后自动进入工作台。

### 后续启动（已有管理员）

1. 点「注册」创建普通用户（`system_role=user`），或点「登录」用已有账户；
2. 同样需填写邮箱、密码、确认密码（仅注册需要确认）；
3. 成功后进入工作台。

> **关于角色**：引擎侧不支持注册时自选角色——首个账户经 `/initialize` 成为管理员（admin），后续 `/register` 一律是普通用户（user）。这是 QiLin gateway 的安全设计。需要变更角色请在 gateway 侧管理。
>
> **字段约束**：邮箱需为合法格式且不是保留域名（如 `.local` 会被拒）；密码至少 8 位，避免常见弱密码；两次密码必须一致，否则前端会拦截提交。

## 5. 未登录访问工作台

落地页点「进入工作台」时，若未登录会被自动拦截到登录页（而非直接进入空工作台）。登录或注册成功后才会进入工作台。

## 6. 开始使用

- 左侧：会话列表与「新研究」入口；
- 中间：对话工作台，输入标的或研究问题，例如：

```text
分析贵州茅台最近一季财报，并生成报告。
```

- 右侧：研究上下文与报告预览；
- 侧边栏底部显示当前登录邮箱，可随时「退出登录」。

## 6. 下次启动

前端启动时会自动探测会话：已登录直接进入工作台，无需重复登录。会话过期后会被引导回落地页重新登录。
