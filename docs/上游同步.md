# 上游同步说明

## 本地源仓库

- QiLin：`/Users/libing/kk_Projects/QiLin`
- KSkills：`/Users/libing/kk_Projects/KSkills`

## 同步命令

```bash
python3 scripts/sync_upstreams.py --refresh-lock
python3 scripts/sync_upstreams.py --sync-qilin
python3 scripts/sync_upstreams.py --sync-skills
```

## 校验命令

```bash
python3 scripts/verify_skill_pack.py
```

## 规则

- 只同步批准清单里的技能
- QiLin 同步到 `vendor/qilin`，作为产品发布输入
- 不直接修改上游仓库
- 所有产品定制留在 KStock

## 同步后的自动重放

- `sync_upstreams.py --sync-skills` 会在复制完成后调用 `patch_vendor_skills.py`
  幂等重放全部本地补丁（脚本修复 + 旧工具引用改写）。
- KStock 自有技能 `kstock/skills/html-report` 也会被重放进
  `vendor/skills/public/html-report`（上游覆盖不丢失，源头在仓库内）。
- 引擎快照（`--sync-qilin`）后需重装引擎依赖并重建产物（快照排除规则会
  连带清掉 `lib/`、`dist/`、`dist-exe/`、`node_modules/`，全部要重建）：

  ```bash
  cd vendor/qilin && ../../scripts/qilin-pnpm.sh install --frozen-lockfile
  ../../scripts/qilin-pnpm.sh run build          # 重建 lib/（exe 构建的 --skip-build 前置）
  cd ../.. && bash scripts/build-engine-bundle.sh --force-exe-build
  ```

  - `--force-exe-build` 必须显式传：`vendor/qilin/dist-exe` 随快照清空后
    仓库级 `dist-exe/kstock-engine` 若仍在，脚本会跳过 exe 构建、打包出旧引擎。
  - 3.0.2+ 引擎新增 `-office` sidecar 目录（LibreOffice 转换依赖闭包，
    SEA 运行时按 `<exe>-office/` 解析，web-app bundle 的 office-to-pdf 依赖它），
    组装脚本已按目录整树复制为 `dist-exe/kstock-engine-office/`。
  - 上游 lock 与快照来自上游**工作树**（非 git 提交），同步前务必确认
    上游工作区干净（`git -C /Users/libing/kk_Projects/QiLin status`）。

## 版本口径

- `upstream.lock.json` 以上游 package.json 为准（如 3.0.4），上游 tag 可能
  领先一个号（v3.0.5），以后者发布、以前者为依赖真源，差异属正常。
