# 报告库工作台式布局设计

## 目标

将报告库从松散的大卡片页面调整为与主工作台一致的紧凑功能界面，提升报告扫描、定位和操作效率。保留现有深墨绿色隐形网格背景以及报告库全部数据能力。

## 页面结构

1. 页面顶部使用固定高度的工作台式状态栏，避开 macOS 红绿灯区域。
2. 状态栏左侧依次放置返回按钮、页面标题和简短说明，右侧放置报告数量与刷新按钮。
3. 主内容区使用居中的单列布局，最大宽度与工作台消息区接近，减少当前页面横向空散感。
4. 搜索框作为内容区首行工具栏，占据可用宽度，不再与页面标题分离成两个松散区域。
5. 报告继续按日期分组，但日期标题使用紧凑分隔栏，并清晰展示当日报告数量。

## 报告条目

报告采用紧凑横向列表项，不再使用固定最小高度的大卡片。左侧展示文件图标，中间依次展示标题、标的、报告类型、分析周期和风险等级，右侧固定放置“打开看板”与删除操作。窄屏下允许信息区与操作区换行，标题不得遮挡按钮。

## 视觉规则

- 沿用首页与工作台的深墨绿色网格背景。
- 顶部栏使用半透明深绿色和轻微模糊，与工作台状态栏一致。
- 列表项使用低对比度边框及透明表面，仅在悬停时增强边框和背景。
- 标题、辅助信息、危险操作继续使用现有文字层级与语义色。
- 圆角控制在 8px 以内，不增加装饰性卡片或无功能图形。

## 行为与数据

报告加载、关键词查询、按日期分组、HTML 预览、刷新和主动删除均沿用现有实现。此次不修改 API、后端存储、报告归档规则或错误处理逻辑。

## 响应式

桌面端维持顶部单行状态栏与横向报告条目；窄屏状态栏允许说明隐藏，工具栏和条目操作区换行。页面仍可纵向滚动，预览弹窗行为保持不变。

## 验证边界

按用户要求，本次由用户自行进行构建、测试与浏览器验证；实现阶段只进行代码修改和静态差异检查。
