# Token 图表悬浮提示与面板开关去重设计

## 目标

为 Token 统计页面的两张 SVG 图表提供一致、可读的悬浮数据提示，同时删除浮动研究上下文面板内部重复的折叠按钮。

## 浮动面板开关

系统状态栏中的 `PanelRight` 按钮保留为研究上下文面板的唯一开关。浮动面板标题栏只显示“研究上下文”标题，不再显示绑定同一 `onToggleRightPanel` 的按钮。面板打开、关闭和内容状态逻辑保持不变。

## 图表悬浮交互

两张图表共用“按鼠标横向位置定位最近日期”的交互规则：

1. 指针进入绘图区时，将指针横坐标换算为 SVG `viewBox` 坐标。
2. 根据 30 天数据点间距选择最近的日期索引。
3. 绘图区显示当前日期的垂直参考线与系列数据点。
4. 图表卡片内显示自定义提示框，位置根据横向索引自动靠左或靠右，避免溢出卡片。
5. 指针离开图表时清除悬浮状态和提示框。

## 提示内容

- 输入/输出 Token 图：日期、输入 Token、输出 Token、当日合计。
- 任务/API 活跃度图：日期、任务完成次数、API 调用次数。
- 所有数值继续使用现有 `zh-CN` 千分位格式化。

## 视觉与可访问性

提示框使用深墨绿色不透明表面、轻边框和现有四个系列色标。参考线使用低对比度虚线，数据点使用对应系列颜色。图表保留现有 `role="img"` 和屏幕阅读器摘要，不依赖浏览器原生 SVG `<title>`。

## 数据边界

不修改 `TokenStatsResponse`、`TokenStatsDay`、Gateway API 或统计汇总逻辑。空数据时不显示悬浮提示；单日数据固定选择唯一日期。

## 验证边界

按用户要求，本次由用户自行进行构建、测试和浏览器验证；实现阶段只进行代码修改和静态差异检查。
