# 股指期货专题分析场景设计

> 版本：v2.0（2026-08-02）
> 状态：设计完成，前端引导入口实现中
> 前置条件：32 个技能全量端到端验证通过（见 [技能可用性报告](技能可用性报告.md)）

## 一、场景定义

**场景（Scenario）= 前端引导词 + Agent 编排流程**。用户在桌面端空态工作台点击场景卡片，
前端将**结构化引导词**填入消息输入框，发送后由 Lead Agent 按引导词编排子代理调用对应技能，
最终交付专题分析结论。

本场景：**股指期货专题分析**——以四大股指期货（IF/IH/IC/IM）为核心标的，
引导 agent 完成「期指维度 → 期权联动维度 → 市场环境维度」三层协同分析，
输出四品种方向矩阵与共振/背离标注。支持**日度 / 周度**双粒度。

## 二、前端引导机制（落地位置：apps/desktop/src/pages/Home.tsx）

### 2.1 数据结构

在 `Home.tsx` 定义场景常量数组（与现有 `quickPrompts` 同层，复用 `onDraftChange` 机制）：

```tsx
interface ResearchScene {
  id: string;          // 场景唯一标识，如 "index-futures-daily"
  title: string;       // 卡片标题，如 "股指期货专题分析 · 日度"
  description: string; // 一句话说明（卡片副标题）
  prompt: string;      // 结构化引导词（点击后填入输入框，多行）
}

const researchScenes: ResearchScene[] = [ /* 见第三节 */ ];
```

### 2.2 交互流程

```
空态工作台（workspace-empty）
  │  ┌─ 研究场景区块（research-scenes）─────┐
  │  │ 场景卡片：标题 + 描述 + 图标          │  ← 新增
  │  └──────────────────────────────────────┘
  │  ┌─ 快捷引导区（quick-prompt-grid）─────┐
  │  │ 单行快捷词 × 4                       │  ← 既有
  │  └──────────────────────────────────────┘
  ▼
点击场景卡片 → onDraftChange(scene.prompt) → 引导词填入消息输入框（可编辑）
  ▼
用户确认发送 → Lead Agent 按引导词委派子代理执行技能编排
```

- 场景卡片点击只填输入框、不直接发送，用户可查看/增删粒度参数后再发送
- 引导词内嵌全部编排约束（密钥激活方式、禁止重定向等），不依赖前端额外配置

## 三、股指期货专题分析场景引导词（v1）

### 3.1 日度（id: index-futures-daily）

```text
【股指期货专题分析 · 日度】请按以下编排流程完成四大股指期货（IF/IH/IC/IM）的期指×期权×市场联动专题分析：

1. 期指维度：委派 general-purpose 子代理，用 read_file 阅读 /mnt/skills/public/futures-analysis/SKILL.md 前 80 行（必须读，密钥注入依赖技能激活），然后执行 cd /mnt/skills/public/futures-analysis/scripts/analysis-engine && python3 analyze_futures.py；转述四品种行情/基差/持仓表与「中信 vs 其他机构」分品种对比表。
2. 期权联动维度：委派 general-purpose 子代理，用 read_file 阅读 /mnt/skills/public/option-futures-linkage/SKILL.md 前 80 行，然后执行 cd /mnt/skills/public/option-futures-linkage/scripts/analysis-engine && python3 analyze_option_futures.py；转述期权维度（认沽认购PCR/ATM IV/IV斜率/Risk Reversal）与 5 维联动信号表。
3. 市场环境维度：委派 general-purpose 子代理，用 read_file 阅读 /mnt/skills/public/market-linkage-engine/SKILL.md 前 80 行，按其说明完成 8 维市场联动分析并转述联动评分。
4. 汇总：构建 IF/IH/IC/IM 四品种方向矩阵（期指信号/期权信号/联动信号/综合方向），按规则标注共振与背离（期指贴水+成交量PCR偏空+RR认沽贵=三向共振偏空；期指升水但PCR偏空=背离；北向净流出+两融下降+IV抬升=环境印证偏空；IF/IH偏多 vs IC/IM偏空=风格切换），给出场景综合评分与一句话结论。

约束：所有子代理禁止 shell 重定向（>、>>、tee、2>），禁止写入文件，禁止探查或替换 /mnt 与 workspace 路径；命令报错原样转述，禁止自行修复。
```

### 3.2 周度（id: index-futures-weekly）

与日度同构，仅替换：

- 步骤 1：`analyze_futures.py` → `analyze_weekly_futures.py`
- 步骤 2：`analyze_option_futures.py` → `analyze_weekly_option_futures.py`
- 汇总口径：周涨跌幅/周均基差/周均 PCR 与 IV（ISO 自然周）

## 四、Agent 编排流程（收到引导词后）

```
引导词（日度）
  │
  ▼
Lead Agent（解析场景 → 并行委派 3 个子代理）
  ├─ Subagent A：futures-analysis ──── 期指四维（行情/基差/持仓/中信vs其他机构对比）
  ├─ Subagent B：option-futures-linkage ── 期权五维 × 5 维联动信号
  └─ Subagent C：market-linkage-engine ─── 8 维市场联动
  │
  ▼
Lead Agent 汇总：四品种方向矩阵 + 共振/背离标注 + 综合评分
  ▼
交付：AI 总结（含方向矩阵表、中信对比表、联动信号表）
```

> 子代理委派由模型自主决策（实测 lead 也可能自行执行部分技能，结果等价）；
> `max_total_per_run=6` 覆盖 3 个子代理上限。

## 五、输出结构（AI 总结应包含）

| 区块 | 内容 | 来源 |
|------|------|------|
| 方向矩阵 | 四品种 ×（期指/期权/联动/综合） | Lead 汇总 |
| 期指维度 | 行情/基差/持仓 + 中信 vs 其他机构对比表 | Subagent A |
| 期权维度 | PCR/ATM IV/IV斜率/RR + 联动信号表 | Subagent B |
| 市场环境 | 8 维联动评分 | Subagent C |
| 结论 | 共振/背离清单 + 综合评分 + 一句话结论 | Lead 汇总 |

## 六、验证方式

1. **前端静态验证**：`tsc --noEmit`（类型） + `vitest run`（单元测试）
2. **交互验证**：桌面端进入空态工作台 → 点击"股指期货专题分析 · 日度"卡片 → 输入框出现引导词 → 发送
3. **端到端验证（L2 沙箱）**：以引导词作为 SSE 任务输入，检查 3 个子代理 completed、方向矩阵/三表齐全、run 自然结束
4. **周度复验**：同法跑周度引导词
