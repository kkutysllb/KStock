# 股指期货专题分析场景设计

> 版本：v1.0（2026-08-02）
> 状态：设计完成（待端到端验证）
> 前置条件：32 个技能全量端到端验证通过（见 [技能可用性报告](技能可用性报告.md)）

## 一、场景定位

以四大股指期货（IF/IH/IC/IM）为核心标的，覆盖**期指行情 → 期权联动 → 市场环境**三个层次，
输出**日粒度 / 周粒度**双模式、单文件离线 HTML 看板的专题深度分析场景。

与既有场景的关系：

| 场景 | 视角 | 差异 |
|------|------|------|
| 市场联动 | 全市场资金与情绪全景（8 维度） | 宏观广角，期货仅是其中一维 |
| 衍生品 | 期权定价与波动率工具 | 单点计算，无品种组合与联动 |
| **股指期货专题（本场景）** | 四大期指为核心标的的专题尽调 | 期指 × 期权 × 环境的纵向深挖 + 分品种横向对比 |

## 三、编排流程

```
用户指令（含粒度：日 / 周）
  │
  ▼
Lead Agent（场景识别 → 并行分派 4 个子代理）
  │
  ├─ Subagent A：futures-analysis ────────── 期指维度
  │    调 analyze_futures.py（日）/ analyze_weekly_futures.py（周）
  │    产出：分品种行情 / 基差 / 持仓 / 中信vs其他机构对比表
  │
  ├─ Subagent B：option-futures-linkage ───── 期权联动维度
  │    调 analyze_option_futures.py（日）/ analyze_weekly_option_futures.py（周）
  │    产出：分品种 PCR / IV / 斜率 / RR + 5 维联动信号表
  │
  ├─ Subagent C：market-linkage-engine ────── 市场环境维度
  │    + zhishu-query（现货基准）
  │    产出：8 维联动评分 + 现货指数快照
  │
  └─ Subagent D：macro-query + news-search ── 宏观与情绪维度
       产出：宏观数据要点 + 政策/情绪新闻条目
  │
  ▼
Lead Agent 汇总（数据合并 + 交叉验证）
  │    构建：4 品种 × 3 维度联动矩阵 + 共振/背离标注 + 场景综合评分
  ▼
report-writer（analysis-report + chart-visualization）
  │    产出：单文件离线 HTML 看板（报告库归档）
  ▼
交付：HTML 看板 + AI 总结
```

### 3.1 并行与依赖关系

- **Wave 1（并行，4 个子代理同时执行）**：A / B / C / D 相互独立，可同时委派
- **Wave 2（串行，依赖 Wave 1）**：Lead Agent 汇总
- **Wave 3（串行，依赖 Wave 2）**：report-writer 渲染

> 子代理委派由模型自主决策；若 lead 选择自行执行部分技能（实测出现过），结果等价，
> 只是并发收益下降。max_total_per_run=6 覆盖本场景 4 个子代理上限。

### 3.2 任务模板约束（沿袭 L1/L2 验证沉淀的经验）

1. **每个子代理第一步必须 read_file 读 SKILL.md 前 80 行**——密钥注入依赖技能激活（SkillActivationMiddleware 机制），不读则 TUSHARE_TOKEN / IWENCAI_API_KEY 不注入，数据全空
2. **禁止 shell 重定向（>、>>、tee、2>）与路径探查**——沙箱重定向失败会陷入诊断循环
3. **禁止输出写入文件**——直接取 stdout
4. **命令模板固定**：`cd /mnt/skills/public/<技能>/scripts/... && python3 <入口>.py <参数>`，报错原样转述、禁止自行修复
5. **长 SKILL.md 只读前 N 行**（如 dcf 1311 行会烧满 turn 预算）

## 四、交叉验证规则（Lead Agent 汇总阶段执行）

| # | 规则 | 判据 | 结论 |
|---|------|------|------|
| 1 | 三向共振 | 期指贴水 + 成交量PCR偏空（>1.2） + RR 认沽贵 | 强偏空（-） |
| 2 | 期指-期权背离 | 期指升水但 PCR 偏空 | 分歧：机构套保 vs 情绪偏空，标注观察 |
| 3 | 环境印证 | 北向净流出 + 两融下降 + 期权 IV 抬升 | 风险偏好恶化，强化偏空结论 |
| 4 | 分品种分化 | IF/IH 偏多 vs IC/IM 偏空 | 风格切换信号（大盘价值 vs 小盘成长） |

## 五、报告结构（HTML 看板）

| 章节 | 内容 | 数据来源 |
|------|------|----------|
| 1. 摘要与结论 | 场景综合评分 + 四品种方向矩阵（期指/期权/联动/综合 4 列）+ 共振/背离标注 | Lead 汇总 |
| 2. 期指维度 | 分品种行情表（价格/涨跌/基差/基差率/持仓变化）+ **中信 vs 其他机构持仓对比表** | Subagent A |
| 3. 期权维度 | 分品种期权指标表（PCR/ATM IV/加权 IV/IV 斜率/RR/IV 差）+ 活跃合约 IV 明细 | Subagent B |
| 4. 联动信号 | 5 维联动信号表（期权信号/期指信号/结论/得分）+ 联动评分 | Subagent B |
| 5. 市场环境 | 8 维联动摘要 + 现货指数基准 + 宏观要点 + 新闻要点 | Subagent C / D |
| 6. 风险与跟踪 | 分品种风险等级 + 需跟踪指标清单 | Lead 汇总 |

> 契约约束沿用 analysis-report：缺失数据分区必须保留并说明缺口；报告不得给出买卖指令，
> 只给研究结论、情景条件、风险等级与跟踪指标。

## 六、日/周双粒度模式

| 模式 | 期指侧（futures-analysis） | 期权侧（option-futures-linkage） | 环境侧 |
|------|---------------------------|----------------------------------|--------|
| 日粒度 | 最新交易日快照：行情/基差/当日持仓变化/当日席位操作 | 最新交易日：PCR/ATM IV/斜率/RR + 日度联动 | 日度 8 维联动 |
| 周粒度 | ISO 自然周聚合：周涨跌幅/周均基差/周末持仓快照/每周席位操作变化 | 周均 PCR/周均 IV + 最新交易日斜率/RR 快照 + 周度联动 | 周度联动 |

参数化方式：`--days N` / `--weeks N`（默认为最新交易日 / 最近 1 周），由用户指令决定或默认日粒度。

## 七、复杂度与预算评估

| 阶段 | 子代理 | 工具调用估算 | 耗时估算 |
|------|--------|-------------|----------|
| Wave 1 | A/B/C/D（并行） | 各 8~15 次 | 60~120s（并行，取最慢者） |
| Wave 2 | Lead 汇总 | 8~12 次 | 30~60s |
| Wave 3 | report-writer | 10~20 次（契约迭代 2~8 轮） | 60~120s |
| **合计** | 4 子代理 + 汇总 + 报告 | **约 50~80 次** | **约 3~6 分钟** |

- recursion_limit=1000 充裕（L1 实测复杂任务 500+ 足够）
- max_total_per_run=6 覆盖（本场景 4 个）
- 若市场环境层可选关闭（`--lean` 变体：仅 A+B），可压缩至 2 个子代理、约 2~3 分钟

## 八、验证计划

3. 周粒度复验（同模板，`--weeks 1` 变体）
4. 通过后在本场景设计中登记验证结果
