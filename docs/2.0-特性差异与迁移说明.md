# 2.0 特性差异与迁移说明

KStock 2.0 从「自建 SPA + Python 引擎 gateway」全面重建为
**QiLin 3.x 插件平台**（TypeScript monorepo，一切皆插件）。本文记录
全部差异、移除项与数据迁移口径。

## 总体架构变化

| 维度 | 1.x | 2.0 |
|------|-----|-----|
| 引擎 | vendored QiLin 2.x Python（editable + monkey-patch） | QiLin 3.x TS monorepo 快照（vendor/qilin），单文件 exe 分发 |
| 桌面前端 | 自建 React SPA（styles.css 7743 行） | 上游插件化工作区 UI + KStock 客户端插件 |
| 业务进程 | gateway（FastAPI）+ 引擎双进程 | 引擎单进程；四库为引擎插件 |
| 数据 API | `/api/v1/kstock/*` | `/kstock-api/*`（同源，无反代） |
| 认证 | gateway 自建邮箱账户（bcrypt）+ CSRF 桥 | `@kstock/accounts-local`（scrypt，用户名或邮箱）+ 1.x 账户自动迁移；注册关闭 |
| 桌面通信 | `app://` 协议反代 + preload IPC 桥 | 直接 loadURL 引擎地址；壳无 IPC 桥 |
| 配置 | runtime.yaml / qilin.config.yaml / QILIN_CONFIG_PATH | bundle patch（代码化）+ 环境变量 |
| Electron | 33（内置 Node 20） | 44（内置 Node 24，满足 node:sqlite） |

## 保留并迁移（数据与体验）

- **1.x 账户自动迁移（`@kstock/accounts-local`）**：2.0 的账户面是上游
  `@qilin/accounts-local` 3.0.0 的 fork（patch 组合器不允许替换行的包名，
  采用「禁用上游行 + insert fork 行」挂载）。旧账户存在旧引擎 SQLite
  （`users` 表，bcrypt 哈希），迁移完全自动、零交互：
  - 引擎启动时若账户文件为空，从旧库（只读，经 `~/.kstock/config/
    qilin.runtime.yaml` 的 `database.sqlite_dir` 定位）导入全部可登录
    账户——升级用户看到的是登录页而非首启初始化页；
  - 账户文件非空时，登录标识未命中则回退旧库按需导入（首次登录即迁移）；
  - 旧 bcrypt 哈希（`$dfv2$`/`$dfv1$`/裸 bcrypt）可直接验证，旧密码原样
    有效；首次登录成功后原位透明升级为本代 scrypt，修改密码亦然。
  - 旧库只读访问，绝不写入；找不到旧库按全新安装处理。
- **四库数据完全兼容**：策略/因子/选股的表结构、`product/kstock.db`、
  文件布局与 1.x 一致；报告库表从引擎 qilin.db 迁到 `product/kstock.db`
  （schema 逐列相同）。旧库里的报告索引行不自动搬家，报告 HTML 文件
  保留在 `~/.kstock/reports/`，需要时重归档即可。
- **数据源凭据迁移**：老 `~/.kstock/config/secrets.env`（`TUSHARE_TOKEN`、
  `IWENCAI_API_KEY` 等）由壳在启动引擎前并入环境（不覆盖已有键），
  数据源状态与相关技能开箱可用。
- **量化四库独立插件**：策略（版本时间线/回测对比/净值叠加）、因子（IC 曲线
  叠加）、选股（重合分析/运行报告）、报告（日期分组/iframe 预览/删除）
  功能对等移植；视觉沿用 KStock 色板与暗色基调。
- **落地页 / 登录注册页**：保留 1.x 设计，作为浏览器直连入口与登录兜底。
- **精选技能**：vendor/skills 原样保留 + 自研 `html-report` 技能（见下）。
- **不迁移**：旧 `qilin.db` 的会话历史（两代引擎数据模型不同）、
  `runtime/qilin/users/<id>/` 用户目录（旧引擎内部状态）。

## 新增

- **`@kstock/quant` 数据宿主插件**：node:sqlite 四库存储 +
  `/kstock-api` 路由（无界面）。
- **量化四库客户端插件**：`@kstock/quant-strategies / -factors /
  -selections / -reports` 各自注册 workspace 侧栏菜单项与 `main` 面板
  （策略库 / 因子库 / 选股库 / 报告库），共享件（数据层 / 小件 / 图标 /
  ksq 样式）由源码型包 `@kstock/quant-ui` 经构建内联。
- **报告库 agent 入库口**：`POST /kstock-api/reports`（显式归档，
  report_id 缺省按 thread+标题稳定派生，重复归档即覆盖更新）。
- **html-report 技能**：替代旧 `render_html_report` 引擎工具。自带
  纯标准库渲染器（内联 SVG：line/area/bar/scatter/pie/radar），单文件
  单主题输出，无外部图表工具依赖；渲染后经入库口归档。
- **profile 首启引导**：壳自动创建 profile（manifest + 插件符号链接），
  仓库移动 / 安装位置变化时自动修复链接。

## 移除（不重建）

以下 1.x 特性在 2.0 中移除，如有需要按新平台机制重建：

| 特性 | 1.x 实现 | 移除原因 / 替代 |
|------|----------|----------------|
| Token 预算刹车 | 引擎 monkey-patch | 3.x 引擎无对应挂点；上游预算机制待评估 |
| Guardrails 设置页 | gateway 路由 + SPA | 同上 |
| 循环检测 / 递归上限 | gateway 路由 | 同上 |
| 定时任务 scheduler | gateway 路由 + SPA | 3.x 引擎 jobs 体系待评估 |
| RBAC / 多用户 | gateway 账户体系 | 单用户产品，账户门已关闭注册 |
| KStock 专用 MCP 工具 | kstock_tools/*（akshare/tushare/四库工具） | 决策：用麒麟原生 MCP + 技能脚本；四库经 `/kstock-api` 入库 |
| `render_html_report` 引擎工具 | kstock_reports_renderer（1401 行，外部图表 URL 契约） | 由 html-report 技能整体替代（自绘 SVG，无两层契约） |
| 线程 outputs 被动扫描归档 | 报告库启动扫描 | 依赖 2.x 目录布局；改为 agent 显式入库口 |
| memory | 1.x 已关闭 | 不变 |
| 引擎配置 runtime.yaml + 备份 | kstock_runtime_config.py | 配置改走 bundle patch / settings.yaml |
| 沙箱 mounts / CSRF origin patch / bash guard | gateway monkey-patch | 3.x 引擎自带沙箱与安全边界 |
| 自建 SPA 的引擎面（chat/SSE/模型设置页） | apps/desktop/src | 上游工作区 UI 对等覆盖 |
| 内置 Python 运行时 | uv + python-build-standalone 随包分发 | 技能脚本走沙箱系统 python3；数据类技能声明依赖 |

## 技能口径变化

- 技能由引擎 `skill-filesystem` 全局层挂载（`KSTOCK_SKILLS_DIR`），
  agent 在沙箱内以 bash + python3 直接执行技能脚本。
- 依赖 numpy/pandas/tushare 的技能脚本在无依赖环境会软降级（已打补丁），
  完整能力需目标环境自行安装依赖。
- 旧 `/mnt/user-data` 虚拟路径的技能文本按 3.x 沙箱约定逐步修订中。
