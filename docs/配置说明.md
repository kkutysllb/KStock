# 配置说明

## 本地路径

- QiLin 上游镜像：`/Users/libing/kk_Projects/QiLin`
- QiLin 产品内置快照：`vendor/qilin`
- KSkills：`/Users/libing/kk_Projects/KSkills`

## 技能清单

批准技能位于 `vendor/skills/approved-skills.json`。

## 上游锁文件

版本锁定文件位于 `upstream.lock.json`。

## 发布规则

- 产品运行和发布优先使用 `vendor/qilin` 内的 QiLin 源码快照。
- `/Users/libing/kk_Projects/QiLin` 只作为上游同步来源，不作为发布包运行依赖。
- 更新上游时先刷新锁文件，再同步 QiLin 和精选技能包。

## 常用环境

- Python：`>= 3.12`
- Node：由工作区依赖提供
- pnpm：由工作区依赖提供
