# 配置说明（2.0）

2.0 没有集中式 YAML 配置文件——配置分三层，均为代码化 patch / 环境：

## 1. Profile 层（`~/.kstock/qilin-home/profiles/kstock/package.json`）

bundle 叠层 `[@qilin/base, @qilin/web-app, dsh-animations, @kstock/web]` 与插件依赖链接。
由壳首启自动创建；引擎 3.0.5 起，缺 `dsh-animations` 层会在启动时被壳幂等补上
（`apps/desktop/electron/lib/profile-bundles.ts`，已存在时不重复写盘）。一般无需手改。

## 2. Bundle patch 层（`kstock/web/cordis.patch.yml`）——KStock 产品配置

按行 id 覆盖上游默认值：

| 行 id | 内容 |
|-------|------|
| system-prompt | KStock 量化研究人格 |
| web-runtime | 端口标签、启动 URL 打印 |
| accounts | 账户门开启、**注册关闭**、会话 7 天 |
| agent-presets | 预设名册（includeShippedRoot=false，随包发 kstock/presets） |
| insert | 挂载 @kstock/web、四库界面、品牌、账户等 KStock 插件 |
| ui-agent-preset | `disabled: true`——由 @kstock/client-presets 替代（固定角色集） |

定时任务（3.0.7 起）不走组合文件：调度三件套随 profile bundles 的
`@qilin/experimental-schedule-bundle` 层挂载（`profile-bundles.ts` 第 4 层），
自研 `@kstock/automation` 已退役。

技能不再经 `KSTOCK_SKILLS_DIR` 精选目录装配（引擎无该变量读取点）：随包技能
来自 preset 目录（`kstock/presets/<role>/skills/`）与安装闭包（含内置动效技能库）。

机器本地覆盖：`$QILIN_HOME/cordis.patch.yml`（优先级最高）。

## 2.1 动效技能库（`dsh-animations`，引擎 3.0.5 起）

- **来源**：上游内置 npm 包，随运行时闭包分发（闭包 +82 MB，113 个 HTML 模板）。
- **层位置**：profile `bundles` 第 3 位（`@qilin/web-app` 之后、`@kstock/web` 之前）；
  缺层时壳与自愈脚本幂等补上；闭包缺包则引擎启动抛
  `cannot resolve profile bundle`（构建期由 `verify_animations_channel` 拦截）。
- **就地升级**：`qilin plugin add dsh-animations@latest`（对部署闭包就地覆盖，
  下次闭包重建会被安装清单版本再次对齐）。

## 3. 环境变量（壳注入）

| 变量 | 说明 |
|------|------|
| `QILIN_HOME` | 引擎 home（profiles/auth/settings） |
| `KSTOCK_APP_DATA_DIR` | 四库 db / 报告文件 / 日志 |
| `KSTOCK_PRESETS_DIR` | 角色预设根（dev 直跑引擎时指向 `kstock/presets`） |
| `KSTOCK_TELEMETRY_*` | 沿用上游遥测开关（`QILIN_TELEMETRY_DISABLED`） |

`KSTOCK_SKILLS_DIR` 为 1.x 历史遗留：3.x 引擎无读取点，仅为旧脚本兼容保留。

## 数据位置

| 数据 | 位置 |
|------|------|
| 四库索引 | `~/.kstock/product/kstock.db`（SQLite） |
| 策略/因子代码与运行产物 | `~/.kstock/product/{strategies,factors,selections}/` |
| 报告 HTML | `~/.kstock/reports/{user}/{Y}/{M}/{D}/` |
| 引擎会话与线程 | `~/.kstock/qilin-home/` |
