# 故障排查

## 1. `pytest` 找不到包

先确认已经安装侧车依赖：

```bash
python -m pip install -e ./sidecar
```

## 2. `pnpm test` 报依赖缺失

重新安装前端依赖：

```bash
pnpm install
```

## 3. Tauri 桌面端没有启动

确认使用的是桌面入口：

```bash
pnpm -C apps/desktop tauri:dev
```

如果 Rust 或系统依赖缺失，先按 Tauri 对应平台的 prerequisites 安装本机依赖。

## 4. Playwright 提示没有浏览器

安装 chromium：

```bash
pnpm -C apps/desktop exec playwright install chromium
```

## 5. 技能包校验失败

重新同步精选技能：

```bash
python scripts/sync_upstreams.py --sync-skills
python scripts/verify_skill_pack.py
```

## 6. QiLin 包看不到或发布包缺失

重新同步 QiLin 内置快照：

```bash
python scripts/sync_upstreams.py --sync-qilin
bash scripts/build-sidecar.sh
```
