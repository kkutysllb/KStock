# 故障排查

## 1. `pytest` 找不到包

先确认 Python 运行时依赖已同步（gateway 依赖由 uv 统一管理）：

```bash
uv sync
```

## 2. `pnpm test` 报依赖缺失

重新安装前端依赖：

```bash
pnpm install
```

## 3. Electron 桌面端没有启动

确认使用的是桌面入口：

```bash
pnpm dev:desktop
```

Electron 主进程会自动编译 `electron/main.ts` → `dist-electron/main.cjs` 并拉起 gateway 子进程；若端口 1420（Vite）或 18001（gateway）被占用，先排查残留进程。

## 4. Playwright 提示没有浏览器

安装 chromium：

```bash
pnpm -C apps/desktop exec playwright install chromium
```

## 5. 技能包校验失败

重新同步精选技能：

```bash
python scripts/sync_upstreams.py --sync-skills
python scripts/verify_skill_pack.py
```

## 6. QiLin 包看不到或发布包缺失

重新同步 QiLin 内置快照（同步后重启 gateway 生效）：

```bash
python scripts/sync_upstreams.py --sync-qilin
uv sync
```

## 7. 用户数据目录异常

如果 sidecar 健康检查返回 `developmentFallback: true`，说明当前没有收到正式应用数据目录，正在使用仓库内 `.kstock`。开发时可以接受；发布包中出现该状态需要检查 Electron 主进程（`apps/desktop/electron/lib/gateway.ts`）是否正确传入 `KSTOCK_APP_DATA_DIR`。

如果线程历史或报告丢失，先检查：

- `QILIN_HOME` 是否指向 `<KStock 数据目录>/runtime/qilin`
- `qilin.runtime.yaml` 中 `database.sqlite_dir` 是否为绝对路径
- 当前 `activeUserId` 是否和线程目录 `runtime/qilin/users/{user_id}` 一致
