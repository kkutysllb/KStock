# KStock v1.0.3 发布说明

> 发布日期：2026-08-11 · Tag：`v1.0.3`

## 版本概览

场景矩阵继续扩展：新增策略研究回测与期权专题两大场景，并对已有场景做产品边界收敛。
> v1.0.2 跳号未发布，本版本直接衔接 v1.0.1。

## 新功能

### 研究场景

- 策略研究回测场景（strategy-research + backtrader_strategies）。
- 期权专题分析场景（options-payoff 期权损益 + options-volatility 期权波动率）。
- 盈利预测与预期差场景完善：盈利预测改走问财网关。
- 指数行情（zhishu-query）并入宏观经济专题场景。

### 产品边界收敛

- DCF 场景调整为仅覆盖 A 股（产品暂不涉及美股 / 港股）。

## 问题修复

- skills：selection-strategies 多因子选股「有效股票不足 3 只」根因修复。
- desktop：ClarificationCard 澄清卡片兜底 options 为字面量字符串时的解析。
