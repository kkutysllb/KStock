# KStock v2.0.0-rc.1 发布说明

> 状态：已发布 · Tag：`v2.0.0-rc.1`（2026-09-28）

2.0 首个发布候选：产品底座换代为 QiLin 3.x 引擎插件形态，量化研究工作台全量重建。

## 新功能

- **引擎底座换代（QiLin 3.0.5，一切皆插件）**：TS monorepo 引擎快照 + 运行时闭包
  分发，Electron 44 / Node 24；账户与四库数据与 1.x 完全兼容，1.x 历史会话不迁移
  （两代数据模型不同）。
- **量化研究四库工作台**：策略库（版本时间线 / 回测对比 / 净值叠加 / 回撤副图）、
  因子库（IC 曲线叠加）、选股库（重合分析 / 运行报告）、报告库（日期分组 / 预览 /
  agent 显式入库口）。
- **财经新闻面板**：实时快讯（60s 刷新）+ 标的识别徽章 + 关注雷达 + 已读管理 +
  热词榜 / 24h 频率条 + 历史检索，一键交 Agent 解读。
- **缠论研究面板**：缠论分析工作台随行挂载。
- **投研角色预设**：standard 隐形基座 + 6 个投研角色（含随行技能目录），
  固定角色集产品口径。
- **动效技能库**：8 个动画技能（ppt-animation / flowchart / network-protocol-viz /
  dynamic-archify / scholar-notes / card-theater / video-shot-demos / phone-ui-demos）
  + 侧栏动效工作台。
- **定时任务**：自研调度器（并发 2 / 单次超时 60min / 停机补跑宽限 15min /
  历史留存 200 条）+ 侧栏「定时任务」管理页 + agent automation_* 六工具。
- **账户与安全**：本地账户门（scrypt；1.x bcrypt 账户零交互自动迁移、旧密码原样
  有效）+ 注册关闭 + 首启管理员初始化（/setup）。
- **桌面发布形态**：三平台安装包（mac zip/dmg、Windows NSIS、Linux deb/rpm）+
  自动更新（后台静默下载 + 系统通知确认 + 退出兜底安装）。

## 体验优化

- **桌面头部几何定稿**：品牌行 / 折叠按钮归位红绿灯行、设置页返回行；
  登录 / 落地页商标统一为 QiLin 印章。
- **设置页整页布局**：全窗设置页 + 分区导航，KStock 分区（数据源 / 量化工作区）随行。
- **外链打开策略**：可嵌链接右侧内嵌浏览器打开（带宿主可嵌性预检），不可嵌链接
  转系统浏览器，无白屏。
- **数据源凭据迁移**：1.x `secrets.env`（Tushare / 问财）启动时自动并入，
  数据源状态与相关技能开箱可用。
- **更新可靠性**：发布契约与产物门禁（V1–V8）、macOS 签名 + 公证 fail-closed、
  Windows 签名主体校验、三平台更新源元数据自动生成与校验。

## Bug 修复

- 1.x 账户在新引擎直接可登（bcrypt 旧哈希兼容验证，首登透明升级 scrypt）。
- 报告库跨库查询消除（表迁至 `product/kstock.db`，schema 逐列兼容）。
- 会话存储 v3 → v4 单向迁移（写打开自动发布 v4，源保留可回滚），旧格式会话
  不再阻塞引擎启动。
- Windows 实机稳定性：发布链九处红路径修复（安装版首启引擎引导、证书入钥匙串、
  产物闭包校验、quant 库句柄关闭等）。
- 内嵌浏览器白屏：外链经宿主可嵌性预检后分流，拒绝 iframe 的站点直接外开。
