# KStock v1.1.0 发布说明

> 发布日期：2026-09-01 · Tag：`v1.1.0`

## 版本概览

本版本把「研究资产」正式产品化：新增因子库与选股库两个资产工作区，
与策略库同构的版本链机制保证研究可复现；任务支持并行执行；侧栏升级为
工作区任务分类汇总。同时完成一轮系统性安全加固（审计 P1×4 + 报告端点
防护），并让应用内更新图标可以直接悬停查看新版本的发布内容。

## 新功能

### 因子库

- 与策略库同构的资产机制：因子身份 / 版本链 / 检验运行记录，版本不可变
  （改定义或参数即新版本）。
- 检验运行锁定「因子版本 × 股票池 × 区间 × 检验配置」，保证结果可复现。
- 对比视图叠加累计 IC 曲线。
- agent 工具（factor_list / factor_create / factor_get_latest 等）接入，
  lead_soul 因子场景新增入库纪律；因子资产只读挂载进沙箱供分析引用。

### 选股库

- 同构机制承载选股方案：要求版本链 + 选股运行报告归档
  （`report.md` + `picks.json`）。
- 跨期对比含命中重合分析；lead_soul 选股场景新增「选股库定位 / 入库（强制）」
  步骤。

### 工作区任务分类

- 侧栏历史任务升级为工作区任务分类汇总：市场分析 / 个股分析 / 选股扫描 /
  策略回测 / 因子研究 / 报告研报 / 宏观行业 / 衍生品专题 / 通用其他，
  共九类。
- 分类由标题关键词在纯读取侧推导，存量任务自动归类，无需手动整理。
- 侧栏标题改为「工作区」并放大字号；目录图标两态默认全闭合；
  任务列表成为侧栏唯一弹性滚动区。

### 任务并行执行

- 流式运行状态从全局单例改为每会话独立管理：前一任务运行中可直接创建
  并发送第二个任务。
- 「停止」只作用于当前查看的会话，不再误伤并行中的其他任务。

### 更新体验：悬停查看新版本发布内容

- 打包版检测到新版本后，侧边栏更新图标就绪时，鼠标悬停（或键盘聚焦）
  即可弹出浮层，直接阅读新版本的发布说明（markdown 渲染）。
- 发布内容优先取更新清单自带说明，缺失时自动回退读取 GitHub Release
  正文，按版本缓存；拉取失败静默降级，不影响更新主流程。

## 安全加固

- 网关代理 Origin 闸门：非可信来源（如沙箱 iframe 的 null origin）
  直接访问网关写接口返回 403，阻断「恶意报告页面对已登录 API 盲打」链路。
- 窗口导航加固：`window.open` 一律拒绝（http/https 转交系统浏览器），
  主框架 `will-navigate` 仅放行白名单来源。
- 关闭本地自助注册（`allow_registration: false`），封堵「本地多用户 →
  自注册 → 提权 → host bash」攻击链；已有用户登录不受影响。
- CSRF Origin / Scheme 判定改为直连实现，忽略可伪造的
  `Forwarded` / `X-Forwarded-*` 请求头。
- 报告内容端点增加 `CSP: sandbox allow-scripts` 与 `nosniff`；
  报告引用链接仅放行 http(s) scheme。

## 问题修复

### 构建与打包

- 打包 runtime 补齐 scipy：修复 factor-research IC/IR 分析（Spearman 相关）
  在产物环境缺失依赖的问题；28 项技能测试全过。
- `vite build` 固定 `NODE_ENV=production`：修复特定环境下开发版 React
  误入产物导致包体翻倍。
- 脚本裸 `python` 调用改为可移植写法。

## 内部质量

- 3392 行的 `Home.tsx` 拆分为 `pages/home/` 八个模块（行为不变）。
- 清理审计确证的死代码约 350 行；删除 7 条无消费的 IPC 死通道，
  桥接契约以 preload 为单一事实源。
- 12 个前端 API client 收敛到统一 fetch 模板与错误体系（净 −254 行）；
  后端收敛原子写 / 数据根等四处同构实现至 `kstock_common.py`。
- CI：GitHub Actions 全部 pin 到 commit SHA；release 工作流权限收敛为
  最小化。
- 全量代码与安全审计报告入库（`docs/代码与安全审计报告.md`），
  历史版本发布说明归档至 `release/`。

## 升级与兼容性说明

- 已关闭本地自助注册：存量用户登录不受影响；新用户开通改由既有管理员
  引导（首次初始化流程不变）。
- 因子库 / 选股库资产随任务自动落位于数据空间 `product/` 目录，
  无需手动迁移。
- 自动更新照常：检测到 v1.1.0 后后台静默下载，完成后图标悬停即可
  预览本次更新内容，点击即重启安装。
