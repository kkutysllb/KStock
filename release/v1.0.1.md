# KStock v1.0.1 发布说明

> 发布日期：2026-08-10 · Tag：`v1.0.1`

## 版本概览

在 v1.0.0 全量底座之上，本版本把五大研究场景（因子研究 / 宏观 / 行业 / 研报 / DCF）
编排成卡片驱动的完整链路，并对桌面端高频交互做了一轮集中打磨。

## 新功能

### 研究场景编排

- 因子研究 / 宏观经济 / 行业分析 / 研报解读 / DCF 估值五大场景编排上线，
  配套三个技能的修复与增强。

### 桌面端交互

- 窗口最大化支持。
- 输入框回车直接发送。
- 折叠交互与设置页视觉对齐。

## 问题修复

- skills：industry-analysis 升级 2.0.2，消除 pywencai 误导性提示。
