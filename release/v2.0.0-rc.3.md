# KStock v2.0.0-rc.3 发布说明

> 状态：待发布 · Tag：`v2.0.0-rc.3`

引擎升级 QiLin 3.0.7 → 3.0.10（98 个上游提交）：侧栏的文件 / Git / 预览三面成批
上线，轨迹图与任务页新增检视视图。本版同时把**引擎消费形态**从「源码快照入库」
改为「fork 分支 + 契约断言」——仓库 tracked 文件由 10267 降到 848，项目目录不再
常驻引擎源码。**从 rc.2 自动更新即可升级，会话 / 账户 / 四库数据零迁移。**

## 新功能

- **侧栏文件面**（引擎 3.0.10）：文件树重命名 / 删除 / 新建、全局文件名搜索、
  上传与拖放；宿主新增 `fs.writeBytes` 原子二进制写入原语并纳入沙箱策略围栏。
- **侧栏预览面**：Markdown 内 Mermaid 图一等渲染（懒加载 + 严格安全 + 缩放模态）、
  作者态原始 HTML 走预览净化器、视频预览（宿主媒体路由 Range 流式）、
  终端字体可选并可点开终端里打印的 URL。
- **交付物「会话变更」页**：跨轮折叠一次会话改动的文件；Git 提交历史分页与
  单提交补丁、`ui-sidebar-git` Git 面板（状态 / 暂存 / 提交 / 分支 / gh PR）。
- **模型可在侧栏打开文件或 URL**（`sidebar-opens`，引擎 base 层）。
- **检视视图**：轨迹图回放、画布操控与记录检查器；任务页任务管理图视图；
  会话侧线程（Sidechat）落在右栏标签页。
- 引擎可选组合包（团队页 / 语音输入 / 自动复核）**不随本版提供**：kstock profile
  的挂载层固定为 `@qilin/base → @qilin/web-app → dsh-animations →
  @qilin/experimental-schedule-bundle → @kstock/web`（前四层自引擎，末层为产品层）。

## 体验优化

- 折叠侧栏不再渲染区域图标按钮（与 KStock 折叠轨口径一致）；轨迹图图例不再
  随侧栏变窄被挤成竖排。
- 滚动条契约收口：三处重绑真正成立、按实际背景判定缩略图层级（页面滚动条回 l1）。
- 引擎门禁存量债清零（lint / 重复度 / 同链预存红），main 触发面与发布视图修复。

## Bug 修复

- `api-workspace-files` 改用 `delete` 作为远端线名（修 Web 启动阻断）；
  `host-sidebar-opens` 补声明 zod（修宿主整批命名空间被撤销）。
- `ui-primitives` tooltip 在无可 ref 的锚点上定位；客户端测试运行时右栏座席
  自渲染死循环；五个客户端包补齐 devDependencies 与发布视图。
- **KStock 侧（本仓）**：引擎消费形态重构——不再 vendor 引擎源码，改由
  `upstream.lock.json`（分支 / 提交 / 基线 / 7 处补丁）+ `scripts/verify_engine_contract.py`
  的 6 类断言锚定；`vendor/` 只剩 `skills`（409 个文件）。引擎克隆按需引导
  （`scripts/engine-bootstrap.sh`），构建完成后可整目录删除释放磁盘。
