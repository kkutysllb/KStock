# KStock v1.0.4 发布说明

> 发布日期：2026-08-11 · Tag：`v1.0.4`

## 版本概览

核心引擎 QiLin 升级至 v2.0.0（多智能体框架），自动更新改为后台静默下载，
长报告阅读体验重做。

## 新功能

### 引擎升级

- QiLin 核心引擎 v1.0.0 → v2.0.0：升级为多智能体框架，保留本地独创能力。

### 桌面端

- 自动更新改为后台静默下载，下载完成后才提示安装（不再打断使用）。
- 长报告按 H1 / H2 切分多段渲染，提升长文档阅读体验。
- 新任务页欢迎文案重构：时段感知问候 + 排版对齐 + 水印。

### 可转债场景

- cb-analysis 新增 Tushare 数据访问层 `cb_data.py`，丰富可转债场景数据维度。

## 问题修复

- desktop：欢迎页副标题多段 + 文本场景下断行错乱（并收紧宽度）。
- skills：option-futures-linkage IV 反解在无 scipy 的沙箱环境下降级失败。
