# KStock v1.0.7 发布说明

> 发布日期：2026-08-15 · Tag：`v1.0.7`

## 版本概览

策略能力产品化：策略工作区（版本链 + 回测记录）入库；设置中心重构并新增定时任务；
窗口失焦时弹系统通知；Windows 侧修复两处存活探测与沙箱路径稳定性问题。

## 新功能

### 策略体系

- 策略工作区：策略版本链 + 回测记录入库，注册为工具供 agent 调用。
- 策略库功能上线，回测与研究流程完善。
- 回测引擎 A 股规则修正（补丁器双写 vendor + dist 保证同步不回退）。

### 设置与通知

- GeneralSettings 重构，新增定时任务配置模块。
- 新增 `showNotification` IPC：窗口非聚焦时弹系统通知。

### 网关与沙箱

- 沙箱挂载宿主路径占位符替换（增量下发 + 占位符替换，附测试覆盖）。
- 行情数据磁盘缓存。

### 界面重构

- McpExtensionsCard / deliveryFiles / Home 重构与样式调整。

## 问题修复

- Windows：`_pid_alive` 改用 `OpenProcess` + `GetExitCodeProcess` 探测存活，
  并捕获 `WinError 87`。
- Windows：沙箱挂载路径混合分隔符修复。
- skills：`tushare_client` 软导入，修复 CI 无 tushare 环境下测试收集失败。
