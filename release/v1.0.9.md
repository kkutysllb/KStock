# KStock v1.0.9 发布说明

> 发布日期：2026-08-23 · Tag：`v1.0.9`

## 版本概览

发布链路集中修复：解决 v1.0.9 三平台构建全挂的打包回归、v1.0.8 自动更新 404、
以及新建会话被空历史覆盖的问题；开发模式支持自动回退到 Python 网关。

## 新功能

### 桌面端

- dev 模式自动回退到 Python gateway（bundle 缺失时不再硬失败）。
- 设置侧栏新增品牌下拉（BrandMenu）。

## 问题修复

### 打包与发布链路

- 修复打包后 `_ctypes` 缺失与 `run_gateway` `sys.path` 注入时序问题。
- 修复 python-runtime smoke 与 POSIX sentinel 导致 v1.0.9 三平台构建全挂：
  POSIX sentinel 改为 stdlib 树内查找；C 扩展复制 / sentinel / smoke 收敛为
  Windows 专属，POSIX 恢复 v1.0.8 行为。
- updater：修复 v1.0.8 更新资源名与 `latest.yml` URL 不匹配导致的自动更新 404。

### 桌面端

- 会话恢复 marker 保护改用 `historyFetchDoneRef`，修复新建会话被空历史覆盖。
- BrandMenu 组件测试断言按实际结构修正。

## 升级说明

- v1.0.8 用户因自动更新 404 无法在线升级，请从 GitHub Release 手动下载 v1.0.9 安装包。
- macOS / Linux 行为与 v1.0.8 保持一致（打包修复不影响 POSIX 运行时行为）。
