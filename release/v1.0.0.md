# KStock v1.0.0 发布说明

> 发布日期：2026-08-06 · Tag：`v1.0.0`（首个正式版本）

## 版本概览

KStock 是一个跨平台桌面端股票量化智能体：核心引擎使用 QiLin（Python 网关侧车），
技能体系只保留适合研究 / 分析 / 报告场景的精选技能。本版本完成从 Tauri 到 Electron 的
整体迁移，打通「桌面工作台 ↔ 内置网关 ↔ 精选技能 ↔ 报告交付」全链路，并建立三平台
签名、公证与自动更新的发布流水线。

## 核心能力

### 桌面工作台（Electron + React）

- 桌面端框架从 Tauri 全面迁移到 Electron，集成网关侧车与应用内自动更新（electron-updater）。
- Claude/ChatGPT 风格对话流：SSE 流式渲染（`sseParser` + `turnReducer` + 阶段推断），
  推理过程与工具调用默认折叠，工具活动展示执行时长。
- Markdown 正文 / 思考 / 报告真正渲染为富文本；自动滚动与「回到底部」浮动按钮。
- 消息编辑重发与对话分支（edit & resend from conversation branches），保留引擎消息身份。
- 输入框模型选择器，会话级 model 记忆；token 预算清零续跑与子代理预算编辑入口。
- 桌面系统集成：系统菜单增强、独立单色透明托盘图标、浮动研究上下文面板、
  可折叠 / 可调宽度的工作区侧栏、推理模式选择器、迷你 K 线流式指示器。

### 账户与数据空间

- 桌面端登录注册，迁移至内置 gateway 认证架构（QiLin 用户上下文桥接）。
- 用户数据空间落地 `~/.kstock`：线程数据空间初始化、报告产物索引、开发数据迁移保护。
- 历史任务管理：侧边栏折叠总标题、时间信息展示、删除任务并同步清理后端 thread 目录。

### 模型与设置中心

- 模型配置真实 CRUD：runtime.yaml 原子读写与备份、`secrets.env` 600 权限、默认模型偏好。
- 设置页统一视觉系统：通用偏好、token 用量仪表盘（悬停明细）、数据源凭据、
  记忆管理与配置、运行与预算配置、工具与沙箱配置、重启后端按钮。
- runtime.yaml `tools` 段增量合并；金融搜索工具落地与护栏配置打通。

### 研究场景与技能（精选技能包）

- 同步上游 18 个股票技能并全量端到端验证；futures-analysis 强化中信 vs 其他机构分品种对比。
- 卡片驱动 agent 编排场景：股指期货专题分析（日 / 周度）、期指期权联动分析。
- 个股缠论专题分析场景（含缠论引擎数据校验修复）。
- 完成可转债、ETF、个股场景构建。

### 报告交付

- 离线 HTML 报告库（dashboard 归档）；新增 `render_html_report_from_file` 工具，
  agent 可直接传 `/mnt/user-data/workspace/report.json` 渲染，无需把大 JSON 读入上下文。
- 报告删除标记机制（`report_deletions` 表按内容摘要隔离）：删除后不再重复归档，
  重新生成不同内容的报告仍可正常入库。

### 首页与数据源

- 首页实时行情新闻滚动条（landing live market news ticker）。
- 数据源连接状态展示（data source connection status）。

## 工程与分发

- 跨平台自包含 gateway：PyInstaller + 内置 Python runtime / stdlib，Windows 生成
  `Scripts/python3.exe` 兼容技能脚本并覆盖 `.libs` DLL 搜索路径。
- 三平台发布产物：macOS（Apple Silicon）`.dmg` / `-mac.zip`（Developer ID 签名 + notarytool
  公证 + staple，PyInstaller Python.framework 双入口签名修复）；Windows x64 `.exe`（NSIS，
  安装前自动终止 gateway 进程树）；Linux x64 `.deb`。不提供 macOS Intel 与 AppImage。
- `build-release.sh` 一键发布：校验 → 版本号同步 → 本地预检 → 生成发布说明 → 打 tag →
  触发 CI；支持 `--resume` / `--no-watch` / `--skip-checks` / `--allow-dirty` / `--delete-tag`，
  失败日志落 `.release-logs/`，推送改为 `git push --atomic`，发布后校验 Release 资产齐全。
- 自动更新：electron-updater 读取 GitHub Release 的 `latest-mac.yml` / `latest.yml` /
  `latest-linux.yml` 差分更新。
- 渲染层 console 与未捕获异常转发到主进程日志（诊断基础设施）；开发日志目录建立。
