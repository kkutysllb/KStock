# KStock v2.0.0-rc.2 发布说明

> 状态：待发布 · Tag：`v2.0.0-rc.2`

引擎升级 QiLin 3.0.5 → 3.0.7：定时任务切换为麒麟原生调度，侧栏菜单置顶，
Windows 实机窗口壳系列修复，更新链安全修复。**从 rc.1 自动更新即可升级。**

## 新功能

- **定时任务 · 麒麟原生调度**：引擎任务页「自动化任务」（左侧栏日历入口）、
  右栏任务标签、会话内定时卡片、`schedule_*` 模型工具（创建 / 删除 / 清单 / 更新），
  支持单次与周期提醒——到期在当前会话投递跟进。旧自研「定时任务」面板退役，
  **存量任务不自动迁移**（两代语义不同：旧版到期开全新会话，新版在原会话投递），
  需要的任务请在任务页按需重建。
- **侧栏菜单置顶**：「自动化任务」与「动效技能库」固定在左侧菜单最上方，
  其后依次为策略库 / 因子库 / 选股库 / 报告库 / 财经新闻 / 缠论研究。
- **引擎 3.0.7 会话体验**：模型选择器模糊搜索、会话字号 10–22 档调节、
  运行态动效与状态指示、详录转写默认开启。

## 体验优化

- **升级零迁移**：会话格式 v4 不变，历史会话、账户、四库数据与数据源凭据
  全部原样保留；首次启动自动补挂调度层（后台一次完成）。
- **Windows 窗口壳**：标题栏控件为系统按钮簇正确让位（含亮色主题下的配色切换），
  登录页 / 落地页底色随页面自报，视觉一体化。
- **Windows 实机运行**（随引擎 3.0.7）：PowerShell 补全态识别、失败步骤的未决
  工具结果结算、终端提示符尾部宽限、沙箱 ACL 诊断技能化。
- **动效技能库入口**：图标与面板直连保持不变，入口位置上移至菜单第二位。

## Bug 修复

- **安全**：自动更新链依赖 js-yaml 高危漏洞（GHSA-2883-xcg3-v3hh）——强制升级
  至 5.4.2，运行时依赖审计清零（详见《项目审计-2.0.0-rc.2》）。
- Windows 安装版首次启动解压失败（打包与解压端 tar 实现不一致）。
- Windows 开发态插件登记失效（junction 链接判定与 Python 包装路径三处）。
- 登录 / 初始化页出现白块（窗口壳底色未随页面自报）；落地页状态标签被
  系统按钮簇遮挡；按钮簇让位挤压胶囊按钮的回归。
- 打包闭包缺调度包导致的引擎启动失败（构建流程缺口，补 runtime bundle 重建步骤）。
- 打开计划文档标签页时 `no registered tab type claims` 抛错（引擎 3.0.7 修复，
  随版本获得）。
