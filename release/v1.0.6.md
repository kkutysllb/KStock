# KStock v1.0.6 发布说明

> 发布日期：2026-08-14 · Tag：`v1.0.6`

## 版本概览

本版本是一次大版本迭代：交付文件获得完整的应用内预览体系；对话流升级为
Cursor/Cline 风格的正文与工具调用交错展示；沉淀技能补丁器三层修复防上游回退；
网关与 Electron 生命周期健壮性集中加固。

## 新功能

### 交付文件应用内预览

- 正文中的交付文件链接改为应用内预览（不再跳系统浏览器），预览层全屏覆盖，
  右上角「返回任务页面」。
- 预览改用 `srcdoc` 内联替代 blob URL：消除 sandbox iframe opaque origin 下的
  CORS 失败、主窗口卸载与生命周期竞态。
- 预览 HTML 清洗：移除 Vite HMR 注入（`/@vite/client`、`@react-refresh`）与 module
  入口脚本，src/href 根相对资源回源到文件所在 origin。
- 预览层用 `createPortal` 渲染到 `document.body`，脱离工作区布局影响，确保工具栏
  按钮永不被遮挡。
- Electron 侧 `will-navigate` 拦截非 dev / `app://` 的主框架导航，防止 React 被卸载。

### 对话流与子代理

- Cursor/Cline 风格：正文与工具调用按真实执行顺序交错展示。
- 运行中的工具卡使用 K 线蜡烛动画表示执行进度。
- 浮动面板显示内置子代理角色名与执行估计；缠论场景改派 chan-theory-analyst 角色，
  技术面择时场景拆分并行委派。
- chan-theory-analyst 角色重定义并正式上岗：system prompt 对齐缠论分析脚本
  （内嵌 chan_theory_v2），白名单补 stock-analysis。
- bash 错误守卫垫片防幻觉 + 委派纪律强制，SOUL 版本化同步。

### 桌面端

- 检查更新结果 toast 反馈；主进程日志结构化（区分已最新 / 有新版本 / 检查失败）。

### 技能健康治理

- 新增技能健康审计工具，修复 3 处隐藏问题（非官方字段 / scipy 硬依赖），
  vendor 同步至上游 fd01489。
- 补丁器沉淀三层修复（Tushare 字段名 / pandas 3.0 兼容 / pywencai 提示），
  双写 vendor + dist，严格幂等检测，防止上游同步回退。

## 问题修复

### 预览链路（根因逐层收敛）

- 相对路径交付链接被 dev server 解析成 SPA fallback 返回 index.html（预览显示
  「KStock 正在加载」）：`openArtifact` 改为经 `toArtifactRequestPath` + `artifactUrl`
  转成 gateway artifact API URL 再 fetch。
- 并发 `openArtifact` 竞态导致「返回任务页面」按钮无效：引入打开序号令牌丢弃过期
  请求，关闭时使 pending 失效（StrictMode 安全，红绿验证）。
- 预览按钮失效修复：`saveArtifactPreview` 改用 `downloadHref` 与 `openArtifact` 同源。
- macOS `hiddenInset` 拖拽区吞点击问题修复。

### 技能修复

- ts/np import bug 链修复（pandas 3.0 兼容），补丁器修 5 个脚本。
- analyze_valuation_models 静默全 0 修复，补丁器字段修复扩展覆盖。
- stk_mins 审计参数格式修复（需 `YYYY-MM-DD HH:MM:SS`），EMPTY 澄清为当日数据未发布。
- 弯引号导致 TSX 编译失败、按钮无事件绑定的回归修复。

### Electron / 网关健壮性

- 退出时同步终止 gateway 进程树（SIGKILL 兜底），修复孤儿进程残留。
- 主进程日志改为每次启动覆盖写入，避免跨启动无限膨胀。
- runtime.yaml 缺段自愈补齐，修复数据空间重建后网关启动 500。
- dev / prod 判断增加 `app.isPackaged` 硬性防护。

## 升级与兼容性说明

- 本版本 tag 曾经历删除重建（脚本支持 `--delete-tag`），以最终 `v1.0.6` tag 内容为准。
