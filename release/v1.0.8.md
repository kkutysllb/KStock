# KStock v1.0.8 发布说明

> 发布日期：2026-08-23 · Tag：`v1.0.8`

## 版本概览

Windows 桌面壳升级为无框窗口：窗控按钮自绘、菜单迁移托盘、快捷键兜底；
首页新闻链路异常可观测。

## 新功能

### Windows 无框窗口改造

- 无框窗口：最小化 / 最大化 / 关闭窗控按钮自绘。
- 应用菜单迁移至托盘。
- 快捷键兜底，保证无框形态下常用操作可达。

## 问题修复

- gateway：landing-news 链路异常记录到 gateway 日志，便于排查首页新闻失效。

## 已知说明

- 本版本 Windows 更新资源名与 `latest.yml` URL 不匹配，导致 v1.0.8 自动更新
  404（已在 v1.0.9 修复）。v1.0.8 用户请手动下载安装 v1.0.9。
